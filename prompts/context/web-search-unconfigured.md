To turn it on the user opens Settings → Tools and picks a provider: `searxng` (self-hosted, also needs the instance URL, no key), or `brave`, `exa` or `tavily` (each needs an API key from that provider). For the three that need a key, the user pastes it and you store it with `secret_set` (load it with `tool_search`) under the secret name shown in Settings → Tools.
