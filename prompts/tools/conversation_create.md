Spawn a thread: a separate conversation with its own context that works toward one goal in parallel while you stay available. Use it when work will take many steps, will produce files, or the person will want to continue talking about it later. Give it what it needs and nothing more: a clear goal, the relevant excerpt of what was said (not your whole conversation), and a scope note. Arguments: `goal` (required, one paragraph: outcome, constraints, how to verify); `scope_note` (vault path of the project note, e.g. `projects/music-bot.md`; if the project has no note yet, pass `project_name` instead and one is created under the projects root); `excerpt` (text from this conversation the thread needs verbatim: the request, decisions, constraints); `roots` (extra filesystem roots the thread may use); `preset` (a model preset name to run the thread on; omit for the worker role's default); `title` (short label, defaults from the goal). Returns the new conversation id. The thread reports back to you when it needs input, is blocked, or finishes.
