Read another conversation's recent transcript: its status, goal, summary, and the last N events (assistant text, tool call names, results in preview form). Use it when a status block looks stale or the person asks what a thread actually did. Arguments: `conversation_id` (required); `limit` (events, default 30, max 200); `before` (event id to page backwards). Returns text. Prefer the project note's status block for routine "how is it going" questions; this is the detailed view.
